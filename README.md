# Overview
###Hello World - My First C# Application

###Description of my software:

*This is my first console application built in C#. The software is a simple, clean console program that outputs "Hello, World!" to the terminal. I built it to understand the structure of a .NET project, including Program.cs, the .csproj file, and how the dotnet CLI compiles and runs code. It's the foundation for building more complex backend applications.*

Purpose for creating this software:

*As a software engineer expanding my skill set, I wanted to get hands-on with the C# and .NET ecosystem. My purpose was to learn how to set up a development environment from scratch, initialize a project using dotnet new, build and run it, and practice version control by pushing it to GitHub. This project is the first step toward building larger applications and APIs with C#.*
